برای صفحه‌های فارسی، فایل‌های بدون تغییر Vazir از نسخهٔ `30.1.0` به‌صورت محلی در frontend قرار گرفتند:

| فایل در `frontend/src/assets/fonts/vazir/` | وزن |
| --- | --- |
| `Vazir-Regular.woff2` | ۴۰۰ |
| `Vazir-Medium.woff2` | ۵۰۰ |
| `Vazir-Bold.woff2` | ۷۰۰ |
| `OFL.txt` | متن مجوز اصلی SIL Open Font License |
| `README.md` | منشأ فایل‌ها و توضیح بسته |

منبع و نسخه در [README فونت](../frontend/src/assets/fonts/vazir/README.md) ثبت شده است. هنگام جابه‌جایی دارایی‌ها، فایل مجوز هم باید حفظ شود.

## نحوهٔ اعمال

در [استایل عمومی](../frontend/src/global_styles/openproject/_generic.sass) سه `@font-face` با نام خانوادهٔ `Vazir`، وزن متناظر، `font-style: normal` و `font-display: swap` تعریف شده‌اند. مسیر WOFF2ها محلی است؛ برنامه برای این فونت به CDN بیرونی وابسته نیست.

متغیرهای زیر فقط تحت `html[lang="fa"]` تغییر می‌کنند:

```css
--body-font-family
--fontStack-sansSerif
--fontStack-sansSerifDisplay
--fontStack-system
```

فونت برنامه و اجزای Primer از این متغیرها استفاده می‌کنند. متن انگلیسی خانوادهٔ موجود سیستم را حفظ می‌کند. فونت مخصوص code یا icon نباید برای جایگزینی عمومی وزیر حذف شود.

footer سازمانی به دلیل فارسی بودن در هر دو زبان، صریحاً خانوادهٔ وزیر را ترجیح می‌دهد. صفحهٔ خطای مستقل ۴۲۲ نیز استایل مناسب برند و فونت را دارد؛ تغییر این صفحه با layout معمول Rails یکسان نیست.

## روش بررسی

1. زبان فارسی را از header انتخاب کنید.
2. در Network مرورگر پاسخ WOFF2 را با وضعیت موفق بررسی کنید.
3. در computed style متن یا ورودی، خانوادهٔ `Vazir` را ببینید.
4. متن معمول، medium و bold و حروف فارسی را مقایسه کنید.
5. به انگلیسی برگردید و حفظ font stack انگلیسی را کنترل کنید.

در بررسی واقعی Production روی HTTPS، computed font ورودی در فارسی با `Vazir` شروع می‌شد و در انگلیسی خانوادهٔ سیستمی قبلی بود. نمایش موبایل نیز بررسی شد. این نتیجهٔ صفحهٔ وب، تأیید کامل شکل‌دهی فارسی در تمام PDFها یا تمام نرم‌افزارهای ایمیل نیست.

## تعویض یا ارتقای فونت

فایل جدید را همراه با مجوز در همان ساختار دارایی قرار دهید، نام خانواده و وزن‌ها را با CSS تطبیق دهید و build کامل frontend/ایمیج را تکرار کنید. صرفاً جایگزینی فایل روی سیستم توسعه، asset از پیش‌ساختهٔ داخل ایمیج Production را تغییر نمی‌دهد.

در صورت نمایش فونت قبلی، ابتدا زبان `html`، پاسخ فایل فونت، computed style و نسخهٔ واقعی ایمیج را بررسی کنید. وابستگی به cache مرورگر و fingerprint فایل باید از خطای تعریف خانواده یا وزن جدا تشخیص داده شود.
