## خواندن نتیجه در کنار روش

روش پیشنهادی یک آزمون، مدرک اجرای آن نیست. برای اینکه بدانید چه چیزی واقعاً اجرا شده، [نتایج ثبت‌شده](10-tests-and-validation.md) را کنار راهنمای تخصصی بخوانید. آخرین بررسی عملیاتی ثبت‌شده ۲۰۲۶-۱۱-۱۴ است؛ افزودن این راهنماها بررسی زندهٔ تازه محسوب نمی‌شود.

اگر مسیر یا helper خصوصی ذکرشده در یک clone تازه نیست، از [تحویل تغییر](49-change-handover-template.md) برای ثبت نیازهای تکرارپذیری استفاده کنید؛ فایل خصوصی را صرفاً برای کامل شدن clone به Git اضافه نکنید.
