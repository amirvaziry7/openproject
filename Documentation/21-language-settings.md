# ۲۱ ـ تنظیمات زبان instance و حساب

[فهرست اصلی](README.md) · [چرخهٔ session](20-language-request-session.md)

## چهار سطح تصمیم

انتخاب session رابط بر نتیجهٔ عادی ترجیح حساب، زبان قابل‌پشتیبانی مرورگر و زبان پیش‌فرض instance اعمال می‌شود. بنابراین تنظیم `OPENPROJECT_DEFAULT__LANGUAGE=fa` تضمین فارسی شدن تمام حساب‌های قبلی نیست.

| تنظیم | اثر | چیزی که تغییر نمی‌دهد |
| --- | --- | --- |
| پیش‌فرض instance | fallback و پیش‌فرض پیکربندی‌شده | ترجیح صریح همهٔ کاربران |
| زبان حساب | ترجیح دائمی همان شخص | زبان حساب‌های دیگر |
| انتخاب header | session مرورگر فعلی | فیلد زبان حساب |
| فهرست زبان‌های فعال | زبان‌های مجاز نصب | ترجمهٔ محتوای کاربر |

## dropdown دو زبانه

template گزینه‌های تولیدشده را به `en` و `fa` محدود می‌کند. حذف گزینهٔ یک زبان از این dropdown، حذف locale آن از repository یا پاک شدن تنظیم کاربران نیست. برای حذف واقعی یک زبان از instance باید موضوع جداگانه بررسی شود؛ در این تغییر چنین پاکسازی‌ای انجام نشده است.

## نصب‌های قدیمی

فهرست زبان ذخیره‌شده ممکن است از نسخهٔ قبلی آمده باشد. وجود فارسی در تعریف جدید تنظیمات به معنی بازنویسی همهٔ مقادیر ذخیره‌شده نیست. تنظیمات زبان مدیریت و environment همان نصب باید با هم بررسی شوند. patch اعتبار پیش‌فرض فارسی را در برخی فهرست‌های قدیمی در نظر می‌گیرد.

## کنترل پس از تغییر

1. یک session تازه بدون ترجیح انتخابی بررسی شود.
2. انتخاب صریح فارسی و سپس انگلیسی در همان مرورگر آزمون شود.
3. یک حساب با ترجیح صریح انگلیسی بررسی شود.
4. تفاوت زبان interface با متن‌های موجود در دیتابیس توضیح داده شود.

در بررسی نهایی ۲۰۲۶-۱۱-۱۴، مقدار واقعی `Setting.default_language` برابر `fa` بود. این نتیجهٔ تاریخی را به عنوان مشاهدهٔ تازهٔ تنظیمات امروز گزارش نکنید؛ برای بررسی جدید، زمان و محیط را دوباره ثبت کنید.
