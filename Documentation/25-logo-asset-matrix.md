# ۲۵ ـ ماتریس مصرف لوگو و کنترل همسانی

[فهرست اصلی](README.md) · [فهرست کامل PNGها و hash](05-logo-and-transparency.md)

## یک master، چند نوع مصرف

| مصرف | نوع دارایی | کنترل مورد نیاز |
| --- | --- | --- |
| ورود و پیش‌فرض برند | PNG | نسبت، ارتفاع CSS و alpha |
| header/theme | aliasهای PNG | همسانی بایت با master |
| منوی باریک/موبایل | wrapperهای SVG | payload، viewBox و نمایش واقعی |
| favicon | SVG عمومی | asset لینک‌شده و cache مرورگر |
| touch icon | نام فایل قدیمی PNG | ابعاد واقعی، نه حدس از نام |
| صفحهٔ ۴۲۲ | payload داخل HTML | جایگزینی مستقل از layout |
| PDF و BIM | PNG متناظر | قابلیت decode و جاسازی |

ده PNG فعلی بایت یکسان دارند. چهار SVG و HTML خطا همان PNG را embedded کرده‌اند. بنابراین تغییر master بدون بازسازی wrapperها، نسخهٔ جدید را به همهٔ مصرف‌کننده‌ها نمی‌رساند.

## کنترل سه‌لایه

1. فایل روی دیسک: SHA256 و ابعاد/نوع RGBA.
2. دادهٔ embedded: decode و تطبیق همان بایت‌ها.
3. پاسخ واقعی سرور: hash asset و مشاهده روی زمینهٔ روشن و تیره.

یک تست تصویر مرورگر می‌تواند نشان دهد لوگو بارگذاری شده، اما فقط دیدن `naturalWidth > 0` شفاف بودن زمینه را اثبات نمی‌کند. شفافیت با decode پیکسل و alpha یا بررسی ساختار تصویر تأیید شد.

## نکتهٔ نگهداری

فایل‌های دارای نام `white` یا `black` در این نسخه الزاماً رنگ جدا ندارند؛ aliasهای لوگوی سازمانی‌اند. فایل SVG فعلی وکتور واقعی نشان نیست. برای طراحی نسخهٔ سادهٔ icon، نیاز به کار جداگانه و تأیید بصری است؛ چنین نسخه‌ای در این مستندات انجام‌شده معرفی نمی‌شود.
