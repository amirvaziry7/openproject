# ۲۶ ـ صفحهٔ مستقل خطای ۴۲۲

[فهرست اصلی](README.md) · [فایل صفحه](../public/422.html)

## چرا این صفحه جداست؟

HTML عمومی خطا می‌تواند خارج از مسیر معمول render layout برنامه سرو شود. بنابراین تغییر partial header یا footer به‌تنهایی نام، لوگو و ظاهر این صفحه را عوض نمی‌کند.

در شخصی‌سازی، عنوان سازمانی، لوگوی embedded، متن سازمانی و استایل مرتبط این صفحه نیز بررسی شدند. لوگوی داخل HTML پس از شفاف‌سازی با payload نهایی جایگزین شد.

## موارد کنترل

| مورد | انتظار |
| --- | --- |
| نام نمایشی | عنوان کامل سازمانی |
| لوگو | همان PNG شفاف نهایی |
| ابعاد | حفظ نسبت پرتره بدون کشیدگی |
| متن پایین صفحه | متن سازمانی ثبت‌شده |
| وابستگی به layout | برای جایگزینی برند فرض نشود |

## بازتولید بررسی

برای دیدن ظاهر مستقل می‌توان پاسخ فایل عمومی را در محیط staging بررسی کرد؛ برای تحریک خطای واقعی امنیتی یا CSRF در Production نیازی نیست. دریافت مستقیم صفحه، صحت همهٔ مسیرهایی را که واقعاً خطای ۴۲۲ ایجاد می‌کنند اثبات نمی‌کند.

پس از تغییر payload، ساختار HTML، اندازهٔ فایل و امکان decode تصویر را کنترل کنید. اگر صفحهٔ اصلی درست و این صفحه قدیمی است، ابتدا خود `public/422.html` و image فعال را ببینید؛ تکرار تغییر partial اصلی مشکل مستقل را حل نمی‌کند.

این تغییر، منطق تشخیص خطا یا پاسخ امنیتی برنامه را برای نمایش برند تغییر نمی‌دهد. وضعیت HTTP و رفتار محافظت درخواست باید مستقل از ظاهر صفحه حفظ شوند.
