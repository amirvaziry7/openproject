## نام نمایشی در برابر قرارداد فنی

در ایمیل، `X-Mailer` از نام نرم‌افزار استفاده می‌کند و رگرسیون Unicode آن آزمون شده است. این تغییر نباید شناسهٔ header، URL یا قرارداد تحویل ایمیل را تغییر دهد.

| حوزه | تغییر ثبت‌شده | حد ثابت |
| --- | --- | --- |
| email metadata | نام نمایشی نرم‌افزار | سازوکار ارسال و شناسهٔ header |
| توضیح پشتیبان | متن برند/ترجمه | مسیر و نام فنی ذخیره‌سازی |
| برنامهٔ موبایل داخلی | نام نمایشی OAuth | UID و redirect URI |
| خروجی‌های تاریخ‌دار | جلوگیری از شمسی شدن مقدار ماشینی | قرارداد میلادی نام فایل |

## معیار بررسی

برای ایمیل، header تولیدشده و متن نمایشی را جدا بررسی کنید؛ فونت صفحهٔ وب لزوماً در نرم‌افزار ایمیل همان نتیجه را ندارد. برای export، تاریخ label روی صفحه را با تاریخ فنی filename یکی نگیرید. مسیرهای ماشینی از تبدیل نمایش با `calendar: false` مستثنا شده‌اند.

تست واحد header موفق بوده است، اما همهٔ ایمیل‌کلاینت‌ها و همهٔ قالب‌های خروجی به‌صورت جامع بررسی نشده‌اند. برای آزمون جدید از تحویل ایمیل test یا محیط مستقل استفاده کنید؛ ارسال واقعی پیام به کاربران بخشی از مستندسازی یا بازبینی ظاهری نیست.
