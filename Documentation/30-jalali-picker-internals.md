# ۳۰ ـ شبکهٔ ماه‌های شمسی در date picker

[فهرست اصلی](README.md) · [افزونهٔ picker](../frontend/src/app/shared/components/datepicker/persian-calendar.plugin.ts)

## تغییر اصلی

picker فارسی با ترجمهٔ نام ماه‌های یک جدول میلادی ساخته نشده است. plugin ماه جلالی و روزهای همان ماه را به نمایش می‌آورد و انتخاب را به روز میلادی متناظر منتقل می‌کند. مدل و منطق محدودیت‌ها همچنان از تاریخ canonical استفاده می‌کنند.

| ویژگی | انتظار طراحی |
| --- | --- |
| single | یک روز منتخب و مقدار ISO متناظر |
| range | دو سر بازه با نمایش شمسی |
| multiple | هماهنگی مجموعهٔ انتخاب با picker پایه |
| min/max و disabled | اعمال بر روز واقعی، نه متن label |
| روز کاری | callbackهای مبتنی بر تاریخ واقعی حفظ شوند |
| datetime | انتخاب روز، ساعت قبلی را ناخواسته صفر نکند |

## چرخهٔ تعامل

نمای فارسی جای تقویم داخلی قابل مشاهدهٔ میلادی را می‌گیرد؛ انتخاب و تغییر ماه باید با state picker پایه هماهنگ بماند. گذر از اسفند به فروردین، طول اسفند کبیسه و حرکت سال از نقاط حساس این ارتباط هستند.

Enter، جهت‌ها و Escape در تست‌های افزونه بررسی شده‌اند. حذف یک grid قدیمی نباید focus قابل‌مشاهده یا دسترسی به روزهای معتبر را از بین ببرد.

## layout

پنل ماه محدودیت عرض دارد تا دو ماه در دسکتاپ و یک ماه در موبایل جا شوند. در فارسی موبایل از picker مشترک استفاده می‌شود؛ واگذاری مستقیم به ورودی native می‌تواند دوباره تقویم میلادی سیستم را نشان دهد.

برای تغییر جدید، هم مقدار selected و هم ظاهر grid را بررسی کنید. تصویری که نام «فروردین» دارد ولی روزهای آن از مارس آمده‌اند، موفقیت محسوب نمی‌شود. برای ماتریس آزمون و نتایج قبلی به [تست frontend](39-frontend-test-workflow.md) مراجعه کنید.
