# ۳۳ ـ گانت و FullCalendar: تفاوت مرز و label

[فهرست اصلی](README.md) · [تنظیم ارائه](../frontend/src/app/core/datetime/calendar-presentation.ts)

## گانت

در فارسی، عنوان و مرز بصری ماه، فصل و سال از دورهٔ شمسی گرفته می‌شوند. تابع `persianPeriod` برای همین ارائه مرز تولید می‌کند. محور و محاسبات زمان‌بندی قرار نیست با تغییر زبان به منطق ذخیره‌سازی شمسی تبدیل شوند.

جهت بخش timeline برای حفظ رفتار محور LTR باقی مانده است، هرچند صفحه و متن‌های اطراف آن فارسی‌اند. معکوس کردن کامل timeline با CSS راه‌حل عمومی RTL نیست.

## FullCalendar

`calendarPresentation(locale)` برای فارسی formatter عنوان، محتوای روز و برخی headerها را تنظیم می‌کند. برای زبان‌های دیگر object خالی برمی‌گرداند تا رفتار قبلی بماند. formatter روز، timezone تنظیم‌شدهٔ تقویم را لحاظ می‌کند.

| لایه | وضعیت فارسی |
| --- | --- |
| عنوان بازه | نمایش تاریخ شمسی |
| شمارهٔ روز | نمایش متناسب با روز محلی |
| برخی headerهای روز | نام روز و تاریخ شمسی |
| planning view interval | همچنان ساختار میلادی قبلی |
| پیمایش بازهٔ برنامه‌ریزی | به ماه شمسی واقعی تبدیل نشده |

## معیار گزارش درست

نمایی با عنوان شمسی الزاماً نمای ماه شمسی کامل نیست. در گزارش نتیجه، «label تبدیل شده» را از «مرز بازه تبدیل شده» جدا بنویسید. این تمایز در FullCalendar محدودیت شناخته‌شدهٔ فعلی است، در حالی که picker مشترک شبکهٔ ماه شمسی واقعی دارد.

برای توسعهٔ بعدی، تغییر interval باید با scheduling، query range، eventهای مرزی و timezone آزمون شود؛ صرف تغییر formatter عنوان برای آن کافی نیست. در این مجموعه چنین ارتقای تکمیلی انجام‌شده معرفی نمی‌شود.
