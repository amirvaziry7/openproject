# ۴۸ ـ مجوزها و پیگیری منشأ دارایی‌ها

## اقلام مرتبط

| قلم | محل ثبت منشأ/مجوز |
| --- | --- |
| کد OpenProject | `COPYRIGHT`، `COPYRIGHT_short` و noticeهای موجود |
| فونت وزیر | `frontend/src/assets/fonts/vazir/README.md` و `OFL.txt` |
| الگوریتم jalaali-js | `doc/licenses/jalaali-js.txt` و package lock |
| لوگوی ارسالی و شفاف‌شده | ثبت ورودی/خروجی و hash در مستندات لوگو |

این فصل جمع‌آوری اطلاعات موجود در repository است؛ حکم حقوقی تازه دربارهٔ تمام شرایط انتشار یا مالکیت نشان سازمانی ارائه نمی‌کند.

## تغییر برند چه چیزی را حذف نمی‌کند؟

جایگزینی عنوان نمایشی با نام سازمان، مجوز و copyright upstream را حذف نمی‌کند. نام OpenProject در namespace و noticeها باید از متن قابل‌برندینگ جدا تشخیص داده شود.

فایل‌های WOFF2 همراه متن مجوز اصلی نگهداری شدند و فایل انتساب الگوریتم تقویم نیز ثبت شد. هنگام انتقال دارایی به مسیر دیگر یا build image، این فایل‌ها را به‌عنوان فایل بی‌استفاده حذف نکنید.

## منشأ و یکپارچگی

شمارهٔ نسخه و hash بایت دارایی دو نقش دارند: نسخه منشأ منطقی را توضیح می‌دهد و hash به تطبیق artifact کمک می‌کند. hash به‌تنهایی مجوز استفاده یا صحت معنایی خوشنویسی را اثبات نمی‌کند؛ بازبینی بصری لوگوی خروجی نیز لازم است.

برای JavaScript/TypeScript جدید، header canonical پروژه با ابزارهای copyright مخزن رعایت شود. تغییر دست‌ساز متن copyright برای نام سازمان، روش اعمال برند نیست. برای استفاده از ابزار به‌روزرسانی header به دستورهای `AGENTS.md` رجوع کنید.
