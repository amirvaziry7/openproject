# Vazir font

Unmodified WOFF2 files from Saber Rastikerdar's Vazir v30.1.0 release:

https://github.com/rastikerdar/vazirmatn/tree/v30.1.0

- `dist/Vazir-Regular.woff2` (400)
- `dist/Vazir-Medium.woff2` (500)
- `dist/Vazir-Bold.woff2` (700)

The original SIL Open Font License is included in `OFL.txt`.
These files are bundled locally with the frontend assets. Persian pages use
Vazir through the application and Primer font variables. English retains its
existing font stack, and code/icon fonts keep their specialized families.
